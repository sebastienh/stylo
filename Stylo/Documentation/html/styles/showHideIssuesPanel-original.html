Show/hide the Issues panel (⇧⌘I)

The Issues panel shows the list of issues associated with the edited stylesheet source. It can not be shown if there are no issue in the stylesheet source. When the Issues panel is shown, all the stylesheet issues are highlighted. When it is hidden, the stylesheet returns to the editing style again.

Show the Issues panel

To show the Issues panel:

  • Click on the Issues button located at the center of the stylesheet tools panel below the style title panel.

Hide the Issues panel

To hide the Issues panel:

  • Click on the Issues button.
