Stylesheet Panel

The Stylesheet Panel includes a title section, a tools section, the stylesheet editor itself and the issues list.

The title section includes:

  • the stylesheet name
  • the back button to return to the Style Inspector

The Stylesheet editor tools section includes, at its center, the Issues indicator button showing the number of issues in the source file.

The issues section includes the list of issues (warnings, errors) in the current stylesheet source.

  • Show/hide the Issues panel
  • Reveal single/all issues
  • Apply pending style changes
