Reveal single/all issues

Highlight a single issue

When the Issues panel appears all the issues in the edited stylesheet source text are highlighted. When highligting an issue, the stylesheet source text may optionnally be scrolled to make it visible.

To highlight a single issue:

  • Click on the issue to highlight in the Issues panel.

Reveal all issues

If an issue is selected in the Issues panel, it is highlighted in the stylesheet source text. When there is no issues selected in the Issues panel, all issues are highlighted in the source file. To reveal all issues, we only need to unselect the currently selected issue.

To highlight all issues:

  • Scroll the issues list up or down to unselect all issues
