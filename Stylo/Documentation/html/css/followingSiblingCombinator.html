Following sibling combinator

following sibling selector matches the elements that are following sibling of an element. It is represented by the sign "~" between the selectors. In the HTML of the previous document, we can use a following sibling selector to select the h2 and p elements as follows:

CSS:

h1 ~ * {
    ...
}

HTML:

<!doctype html>
<html>
    <body>
        <h1>title 1</h1> 
        <h2>title 2</h2>
        <p> 
            <h2>title 2 in p</h2>
        </p>
    </body>
</html>
