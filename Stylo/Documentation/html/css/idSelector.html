Id selector

The id selector allows to select elements using the id attribute. It takes the general form of the hash sign followed by the id attribute's value: #<element id>. In the following HTML document:

HTML:

<!doctype html>
<html>
    <body>
        <h1 id="my-first-title">Title 1</h1>
        <h2>Title 2</h2>
    </body>
</html>

it is possible to assign the red color to the element h1 using the following style declaration:

CSS:

#my-first-title {
    color: red;
}
