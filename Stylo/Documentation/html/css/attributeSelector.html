Attribute selector

The attribute selector allows to select elements based on the presence/absence or value of any attribute. It takes the general form of the name of the attribute optionally followed by a text selection expression and the partial or complete value of the attribute, all placed between a left square braquet '[' and a right square braquet ']'.
