Attribute value

The attribute value selector selects elements based on the value of an attribute. To use it, we need to place the name of the attribute in square brackets, followed by the text selection expression, followed by the match text.

There are six differents text selection expressions:

  • Exact match
  • Contains word match
  • Starts with word match
  • First word begins with substring
  • Last word ends with substring
  • A word contains substring
