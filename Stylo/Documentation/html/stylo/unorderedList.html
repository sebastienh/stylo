Unordered list

To create an unordered list:

  • Textually, enter - at the beginning of each line of the list
  • From the menu, choose: Format→Unordered List
  • From the Markdown Quick Formatting Tools, select the text to be transformed into a unordered list and click on the - button.
  • With the keyboard shortcut, enter ⌘L

See Markdown reference for more information.
