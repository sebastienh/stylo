Files Outlines Panel Title Bar

The Files Outlines Panel Title Bar displays a popup menu to select the currently displayed Files Outline View. This popup also will reflect any change in the currently selected Files Outline View made through the Editor's Panes.

Change the currently selected Editors Pane and Files Outline View

To change the currently selected Editors Pane and Files Outline View:

  • from the Files Outlines Panel Title Bar center popup menu, choose the menu item with same title as the required Editors Pane's name.

  • from any editor shown in an Editors Pane, click in any editor under the required Editor Pane.
