Preview Window

The preview window displays the preview in different formats for all the selected documents in the current Editors Panel in their order of appearance. At the center of the window, the format selector popup button allows to select a preview format. On the right, the export button allows to export the selected files as a single file in the chosen format.

Five preview/export formats are currently supported:

  • PDF
  • Docx
  • Markdown
  • HTML
  • Text
