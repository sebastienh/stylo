
# Markdown

Markdown est le language de balises léger utilisé dans Stylo. C'est un language simple qui met l'accent sur la lisibilité et la facilité d'utilisation. Markdown existe en plusieurs versions mais une version semble de plus en plus faire consensus: CommonMark, et c'est la version implémentée par Stylo. Pour tout question relative à la syntaxe Markdown, le site officiel de [CommonMark](https://commonmark.org/) offre une [documentation](https://spec.commonmark.org) complète et un [outil d'essai en ligne](https://spec.commonmark.org/dingus/). 

Markdown définit une syntaxe qui se veut non intrusive et qui permet de définir des éléments HTML. En dernier ressort, puisque que du code HTML valide est interprêté comme tel par Markdown, il est toujours possible d'utiliser HTML dans un document Markdown. 

Il est à noter qu'il n'existe pas de Markdown « invalide ». Un document texte est un document Markdown valide. Si une balise n'est pas reconnue elle sera simplement interpétée comme du texte.   

## Éléments  

Voici un inventaire simplifié des règles de syntaxe principales dans CommonMark et Stylo. Se référer à la [spécification CommonMark](https://spec.commonmark.org) pour plus d'information.

Dans Stylo, un élément peut aussi définir une ou plusieurs sous-régions qui peuvent être ciblée(s) par un pseudo-élément. Pour chaque élément où c'est possible les pseudo-éléments associés seront listés dans la section se rapportant à l'élément dans la sous-section « Pseudo éléments ». 


### Titres  

#### Syntaxe  

##### Titre de niveau 1 

Un titre de niveau 1 peut s'écrire de deux façons, avec un dièse, comme dans l'exemple suivant:    

Markdown: 

``` markdown 
# titre 1
```

HTML:

``` html
<h1>titre 1</h1>
```

``` swift
func test() {
	print("nothing")
}
```

Un titre de niveau 1 peut aussi s'écrire en soulignant d'une ligne double (formée de signes « égal » (=) accolés les uns aux autres.  

Markdown: 

``` markdown
Titre 1 
=========
```

HTML:

``` html
<h1>titre 1</h1>
```

##### Titre de niveau 2

Markdown: 

``` markdown
## titre 2 
```

HTML:

``` html
<h2>titre 2</h2>
```

Comme pour le titre de niveau 1, une syntaxe « soulignée » existe pour le titre de niveau 2: 

Markdown: 

``` markdown
Titre 2
--------------
```

HTML:

``` html
<h2>titre 2</h2>
```

##### Autres niveaux 

Les autres niveaux s'écrivent avec 

``` markdown 
### titre 3
#### titre 4 
##### titre 5 
###### titre 6 
``` 

#### Pseudo éléments

Tous les titres offrent le pseudo-élément suivant: 

- "tag": permet de styliser la région servant à définit le titre, dans le cas de la syntaxe avec dièses, seulement les dièses seront stylisés, et dans le cas de la syntax « soulignée », la barre de soulignement sera stylisée. Par exemple, le CSS suivant colorera la partie « tag » des éléments « h1 » avec la couleur rouge: 

``` css 
h1::tag {
	color: red;
}
```

### Barre horizontale 

La barre horizontale sert à séparer du contenu ou souligner du contenu, par exemple un titre. Elle est représenté par une barre horizontale de la largeur du document. 

#### Syntaxe 

Markdown: 

``` markdown 
---
```

ou 

``` markdown  
***
```



### Emphase  

Il existe deux type d'emphase qui correspondent aux deux éléments HTML « strong » et « em ». L'élément « strong » délimite du texte important et est généralement stylisé avec du texte gras. L'élément « em » délimite du texte emphasé et est généralement stylisé avec du texte en italique.                                      
                       

#### Syntaxe 

Pour mettre de l'emphase sur une section de texte, il suffit de l'entourer d'une « * » (étoile) ou d'un « _ » (signe de soulignement) de chaque côté: 

Markdown: 

``` markdown 
*Texte emphasé*
_Texte emphasé_ 
```

HTML: 

``` html
<em>Texte emphasé</em>
<em>Texte emphasé</em>
```                                        

Pour définir une section de texte important, il suffit de l'entourer de deux « * » (étoile) ou de deux « _ » (signe de soulignement) de chaque côté: 

Pour mettre le texte important: 

Markdown: 

``` markdown 
**Texte important**  
__Texte important__
```

HTML:

``` html
<strong>Texte important</strong>
<strong>Texte important</strong>
```             

#### Pseudo éléments

Les pseudo-éléments offerts par ces deux éléments sont: 

`tag`: couvre les étoiles ou les signes de soulignement utilisés pour définir l'emphase des deux côté du texte. 

`opening-tag`: couvre les étoiles ou les signes de soulignement utilisés pour définir l'emphase au début du texte.   

`closing-tag`: couvre les étoiles ou les signes de soulignement utilisés pour définir l'emphase à la fin du texte.   


### Bloc de citation 

Un bloc de citation, équivalent de l'élément HTML « bloquote », sert à identifier une section de texte cité d'une autre source. 

#### Syntaxe 


Markdown: 

``` markdown 
> Bloc de citation    
Bloc de citation 
```

HTML:

``` html
<blockquote>
	<p>
		Bloc de citation<br>
		Bloc de citation
	</p>
</blockquote>
```

Les blocs de citation peuvent s'imbriquer les uns dans les autres: 

Markdown:

``` markdown 
> Bloc de citation    
> > Bloc de citation imbriqué
> > > Second bloc de citation imbriqué
```

HTML:

``` html
<blockquote>
	<p>
		Bloc de citation
	</p>
	<blockquote>
		<p>
			Bloc de citation imbriqué
		</p>
		<blockquote>
			<p>
				Second bloc de citation imbriqué
			</p>
		</blockquote>
	</blockquote>
</blockquote>
```

#### Pseudo `éléments

Les pseudo-éléments offerts par cet élément sont: 

`tag`: couvre les signes « > » (plus grand) utilisés pour définir les blocs de citation. 
 

### Listes 

Une liste en Markdown, équivalent de l'élément « ul » ou « ol », pour « unordered list » et « ordered list », est une suite d'éléments appartement à un même ensemble logique. Comme dans sa version HTML, une liste peut être ordonnée ou non-ordonnée. 

#### Syntaxe 

#### Non ordornées  

Markdown: 

``` markdown 
* Élément de liste
* Élément de liste
* Élément de liste
```
ou 

``` markdown 
- Élément de liste
- Élément de liste
- Élément de liste
```

HTML:

``` html
<ul>
	<li>Élément de liste</li>
	<li>Élément de liste</li>
	<li>Élément de liste</li>
</ul>
```

#### Imbriquées 

``` markdown 
* Une puce
* Une autre puce
    * Une sous-puce
    * Une autre sous-puce
* Et encore une autre puce !
```

#### Ordornées  

``` markdown 
1. Élément un 
2. Élément deux
3. Élément trois
```
ou 

``` markdown 
1) Élément un 
2) Élément deux
3) Élément trois
```

HTML:

``` html 
<ol>
	<li>Élément un</li>
	<li>Élément deux</li>
	<li>Élément trois</li>
</ol>
```

On peut aussi commencer le numérotage à une valeur précise, comme dans l'example suivant:

``` markdown 
57. Élement 57
1. Élement 58
```

HTML:

``` html 
<ol start="57">
	<li>Élement 57</li>
	<li>Élement 58</li>
</ol>
```

#### Pseudo éléments

Dans le cas des listes, ce sont les éléments qui contiennent des pseudo-éléments. 

`tag`: couvre le signe du type d'élément (ordonné ou non).

Dans l'exemple précedent nous pourrions mettre « 57. » et « 1. » en rouge en utilisant le CSS suivant: 

 ``` css
li::tag {
	color: blue;
}
```

ou plus spécifiquement les éléments de listes ordonnées: 

 ``` css
ol li::tag {
	color: blue;
}
```

### Code

Un élément de code est tout élément qui contient du code source d'un language de programmation ou d'un language de balise. Il existe trois types d'éléments code en Markdown: « en ligne », « clôturé » et « indenté ». 

Les éléments de ce type sont utilisés en Markdown pour indiquer qu'une section de text ne fait pas partie du même espace syntaxique que le présent document. 

Par exemple dans l'example suivant: 

``` markdown 
# titre 
```

Le titre Markdown « # titre » n'est pas un titre en fonction de l'espace syntaxique courant: il l'est en regard du bloc de code qui le contient, mais dans le document courant, c'est un block de code. 

#### Syntax 

##### En ligne

Un élément code en ligne se définit à l'intérieur d'une ligne et est délimité par deux accents graves « ` », une au début, et l'autre à la fin de la section de texte que l'on veut définir comme un élément « code ». 

Markdown: 

``` markdown
Une ligne avec du `code`. 
```

HTML:

``` html
	<p>
		Une ligne avec du <code>code</code>.
	</p>
```

##### Clôturé

Si l'on veut définir un élément code sur plusieurs lignes, on doit utiliser la syntaxe clôturée qui permet de définir le début du code et la fin sur des lignes différentes. Dans ce cas, il faudra utiliser trois accents graves côte-à-côte au début d'une ligne, optionnellement suivit d'un paramètre, générallement le nom du language utilisé, et terminés avec trois accents graves. Tout le texte entre ces deux balises sera considéré comme du code. Voici un exemple: 

Markdown: 

<pre><code>
``` markdown 

func estPair(nombre: Int) -> Bool {
	return nombre%2 == 0 
}
```
</code></pre>




<div>
</div>


HTML:

``` html
<pre><code>func estPair(nombre: Int) -> Bool {
	return nombre%2 == 0 
}
</code></pre>
```

##### Indenté

Une troisième alternative pour définir une section code est la syntaxe indentée. Il suffit de placer 4 espaces ou plus au début de chaque ligne de code, comme ci-dessous: 

Markdown/HTML: 

<pre><code>
    // Commentaire
    ligne 1 du code
    ligne 2 du code
    ligne 3 du code
</pre></code>

HTML:

``` html
<pre><code>// Commentaire
ligne 1 du code
ligne 2 du code
ligne 3 du code</code></pre>
```

#### Pseudo éléments

Il exites des pseudo-éléments pour le code en ligne et le code clôturé, le code indenté n'en contient pas puisque le marqueur est l'espace. 

Le code en ligne et le code clôturé contienne les pseudo-éléments suivants: 

`tag`: définit les intervalles de texte des balises ouvrante et fermante des deux versions de code balisés: le `\`` dans le code en ligne et le ````` dans le cas du code clôturé.  

`opening-tag`: les trois premiers accents grave, ceux ouvrant le block de code.  

`closing-tag`: les trois derniers accents grave, ceux fermant le block de code.  

Et le code clôturé supporte en plus le pseudo-élément: 

`code-fence-params`: qui  contient la portion de texte des paramètres au code clôturé. 

### Tables

Une table sert à mettre sous forme de tableau de l'information. Elle correspond à l'élément HTML « table ». 

#### Syntaxe 

Chaque rangé d'un tableau commence au début d'une ligne et est indiquée par une barre verticale: « | ». Chaque colonne est séparée des précédentes par une barre verticale, et la dernière colonne d'une rangée se termine par une barre verticale. 

La première rangé est la rangée titre. Elle permet de donner un titre à chacune des colonnes de la table, le titre de chaque colonne peut être vide, mais il est important que le nombre de colonne soit égale au nombre de rangés désirées dans la table. 

La deuxième rangé est la rangé des séparateurs. Elle sépare la rangé titre des rangés de valeurs. Chaque colonne de cette rangée, comme celle des titres, commence par une barre verticale, et la denière colonne se temine par une barre verticale. Chaque colonne doit contenir au minium un tiret « - ». Ce tiret peut optionnellement être précédé suivit d'un deux-points « : » pour spécifier un alignement à gauche de la colonne correspondante, ou un alignement à droite, respectivement. L'abcence de deux points signifiant un alignement au centre. 

Ensuite, viennent les rangés des valeurs. qui suivent le même modèle que la rangé titre mais contient les valeurs de chaque colonne. 

Quelques exemples: 

Une table avec deux colonnes centrées et trois rangés de valeurs: 

Markdown: 

``` markdown
| Colonne 1 | Colonne 2 |
| - | - |
| Texte colonne 1   | Texte colonne 2 |
| Texte colonne 1   | Texte colonne 2 |
| Texte colonne 1   | Texte colonne 2 |
```

HTML

``` html
<table>
    <thead>
        <tr>
            <th>Colonne 1</th>
            <th>Colonne 2</th>
        </tr>
    </thead>
    <tbody>
        <tr>
            <td>Texte colonne 1</td>
            <td>Texte colonne 2</td>
        </tr>
        <tr>
            <td>Texte colonne 1</td>
            <td>Texte colonne 2</td>
        </tr>
        <tr>
            <td>Texte colonne 1</td>
            <td>Texte colonne 2</td>
        </tr>
    </tbody>
</table>
```

Une table avec les colonnes alignées à droite:

Markdown: 

``` markdown
| Colonne 1 | Colonne 2 |
| ------:| -----------:|
| Long texte de la colonne 1   | Long texte de la  colonne 2 |
| Long texte de la  colonne 1  | Long texte de la  colonne 2 |

```

HTML:

``` html
<table>
    <thead>
        <tr>

            <th style="text-align:right">Colonne 2</th>
        </tr>
    </thead>

        <tr>
            <td style="text-align:right">Long texte de la colonne 1</td>
            <td style="text-align:right">Long texte de la  colonne 2</td>

        </tr>
    </tbody>
</table>
```

Markdown:

|:------|:-----------|
| Long texte de la colonne 1   | Long texte de la  colonne 2 |

#### Pseudo-éléments 

L'élément « table » supporte le pseudo-élément `tag` qui contient tous les séparateurs verticaux ainsi que la ligne qui sépare la rangé titre des rangés données. Il peut être utilisé comme suit: 

``` css
table::tag {
	color: orange;
}
```

### Liens 

Un lien est un élément qui permet d'insérer un URI (Unique Resource Identifier), ou plus simplement un URL (Unique Resource Locator) vers une resource. Cet élément correspond à l'élément « a » (anchor) de HTML et est communément utilisé pour faire référence à du contenu sur Internet. 

#### Syntaxe 

Il existe deux syntaxes principales pour les liens, la différence résidant en la manière de spécifier l'URI: avec ou sans référence. Une référence (voir la section « Référence » pour plus d'information) est un identifiant donné à un URI et qui peut être utilisé au lieu d'un URI dans un lien (ou une image). 

La syntaxe d'un lien est la suivante: 

[texte du lien](adresse"titre")

Dans un lien avec syntaxe sans référence, l'adresse est un URI, et dans l'autre cas, l'adresse est une référence (elle même pointant sur une adresse).  

Il est aussi possible d'ajouter un titre à un lien.

##### Sans référence 

Markdown: 

``` markdown 
[texte du lien](www.textually.net/stylo)
```

HTML: 

``` html 
<p><a href="www.textually.net/stylo">texte du lien</a></p>
```
ou  avec titre: 

Markdown:

``` markdown 
[lien avec titre](www.textually.net/stylo "Stylo!")
```

HTML: 

``` html 
<p><a href="www.textually.net/stylo" title="Stylo!">lien avec titre</a></p>
```

##### Avec référence 

Markdown: 

``` markdown 
[lien][idStylo] 

[idStylo]: www.textually.net/stylo
```

Note: Si une référence inexistante est utilisée dans un lien, celui-ci sera considéré comme du texte.

## DOM 

Dans Stylo, CSS est utilisé pour « styliser » le texte Markdown. Certains éléments de Markdown sont éliminés lors de la conversion en HTML; que l'on pense aux références qui ne sont remplacées par la destination du lien lorsqu'utilisées dans un lien. Afin de permettre de styliser aussi les éléments de Markdown, Stylo créé des éléments Markdown dans un espace de noms ( « namespace » ) séparé. Pour ceux qui savent comment utiliser un « namespace » en CSS, le « namespace » de Markdown est définit comme: `"http://net.daringfireball.markdown"`, pour les autres, il n'est que très rarement utile d'utiliser un « namespace » dans un sélecteur CSS. 

Les éléments qui ont été ajoutés sont les suivants: 

- `html-block`: HTML peut être utilisé directement dans Markdown. Dans Stylo, les blocks de code en HTML sont groupés sous des éléments de type: `html-block`. 
- `reference`: Une référence prend la forme: [<nom de la rérérence>]: <url de destination> "<titre>". Il est possible de styliser une référence Markdown avec l'élément `reference`
