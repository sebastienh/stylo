
# Tags Plugin

The _tags plugin_ allows to visualize all the tags in all [_editors panel_](../stylo#editorsPanel). It complements the [Markdown Attributes](../markdown#mdAttributes) and bring them to life visually in the [Tags Tools Panel](#tagsToolsPanel). We can then select them, which highlight them in the target [_editors panel_](../stylo#editorsPanel) and navigate through them.
