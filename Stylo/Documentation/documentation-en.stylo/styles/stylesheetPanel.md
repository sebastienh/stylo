
# Stylesheet Panel

The _Stylesheet Panel_ includes a title section, a tools section, the stylesheet editor itself and the issues list.

The title section includes:

- the stylesheet name
- the back button to return to the _Style Inspector_

The _Stylesheet editor tools_ section includes, at its center, the _Issues indicator button_ showing the number of issues in the source file.

The issues section includes the list of issues (warnings, errors) in the current stylesheet source.
