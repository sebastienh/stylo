
# Apply pending style changes (`⇧⌘C`)

Changes made when editing stylesheets of a style are not applied automatically to the Markdown text for performance reasons. It must therefore be explicitly requested to apply style pending changes. This is the purpose of the `Update Document Style` button (located at the right of the _Style Inspector_). It will only be enabled if there are differences between the currently applied style and the edited style.

To apply pending changes::

- From the style's _Style Inspector_ tools panel, click on the `Update Document Style` button
