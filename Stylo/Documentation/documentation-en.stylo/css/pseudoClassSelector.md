
# Pseudo-class selector 

A pseudo-class selector specifies a special state of an element. Stylo supports 5 pseudo-class selectors `:root`, `:fade`, `:focus`, `:highlight` and `:flash`.

## :root 

The `:root` pseudo-class selector allows to selector top most element in the styled document tree. For an HTML document, which Markdown is in Stylo, it refers to the `<html>` element. 

## :focus 

In focus mode, some elements becomes `focus`, this pseudo-class allows you to define a particular style for an element while it is in `focus` mode.  

## :fade 

In focus mode, while some elements become `focused` other have to fade. The `:fade` pseudo-class allows you to define a particular style for an element while it is in `fade` mode.  

## :highlight 

The `:highlight` pseudo-class is used when `tags` are highlighted using the _Tags_  plugin, to make more _evident_ the relevant parts of the text. 

## :flash

The `:highlight` pseudo-class is used when selected `tags` are navigated using the _Tags_  plugin.
